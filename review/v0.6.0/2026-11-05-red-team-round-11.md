## What this round says about the approach

- **The state-surgery writer table is the largest defect left (C4 to C11, R6-1, R6-3).** Eight criticals are one design: each program's way of naming a target is a row, and the strict shapes let the program through as plain. The same lesson as the option deny lists in round 10, one level down. A rule that covers the family: for a plain program that is not on the read-only list, any word, option value or glued fragment that resolves to a state file (or to a directory that holds one) is state surgery; programs known to be read-only keep their current treatment. This is how guard files already work ("a program that names a guard file is tampering unless on the read-only list"), and it closes the spellings the table does not list, at the cost of asks for commands that merely name a state file. Directory-valued targets (`find`, `rm -r`, `tar -C`, `~+`) need the same expansion of what the word means.
- **zsh is the shell Claude Code runs on macOS and the model is bash's (C1 to C3).** Three criticals in the first pass, and the reviewer's untested list (`$=x`, arrays, `zmodload zsh/mapfile`, `emulate -c`, global aliases, `autocd`, `zmv`, `zargs`) is the next family. Either the analyzer implements the zsh semantics that differ from bash for every command, or a command whose shell is zsh and that uses one of them is unseen code.
- **A round-10 fix introduced a crash (R5-1).** The new unresolved-name rule has no test for an empty positional list, and a panic discards the verdict on the rest of the command. Two changes: guard the slice, and make a recovered panic or analysis error fail closed whenever a known infrastructure program appears in the command.
- **Unreported directories (R3-1) and loaded environments (R6-2) are the same mistake as the round-10 backstop:** information the hook does not have is treated as known. A relative path with an unknown base, and a variable set in a file a runner loads, are both unknown.
- **The docs overstate again in places the tests did not cover (R6-3, R6-6, R6-8, R6-9).** Documentation claims for the state and judge bullets should have a scenario each; the three here were caught by a reviewer who read them against the code.
